Project Overview
The Digital Lost and Found System (DLFS) is a web-based platform designed for the Bahria University Islamabad Campus. It addresses the limitations of manual, paper-based tracking by allowing community members to report lost or found items, search a live database, and manage claims through an automated matching engine.

Repository Structure & Milestones
This repository demonstrates full version control usage across four key milestones:

Milestone 1: Requirements
Problem Statement & Scope: Analysis of the discoverability gap and administrative burdens in current systems.

Requirements: Comprehensive lists of Functional (FR-01 to FR-15) and Non-Functional requirements.

Use Cases: Detailed diagrams and description tables for core system interactions.

Milestone 2: Modeling
Data Flow: Context Diagram and Level 1 DFD.

Structural Models: Domain-specific Class Diagram.

Behavioral Models: Sequence, Activity, and State diagrams modeling the item lifecycle.

Milestone 3: Design & Architecture
Architecture: Implementation of the MVC (Model-View-Controller) pattern with a dedicated Service Layer.

Database Design: Relational schema including 7 core tables (Users, Reports, Matches, Claims, etc.).

Milestone 4: Testing & Management
Test Plan: Unit, Integration, and System testing strategies.

Test Cases: Sample cases covering successful submissions, validation failures, and security access.

Project Planning: Gantt and PERT charts documenting the development timeline.
